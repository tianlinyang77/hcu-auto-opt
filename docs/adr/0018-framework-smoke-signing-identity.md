# ADR-0018：Framework Smoke 独立签署身份

状态：实现中，待审；不是人工验收决定。

## 原因

原签核 API 接收调用方 actor 字符串，Repository 校验状态/证据/幂等，但不校验请求身份。
只读结果页接写入口前，必须先补身份边界，避免绕过页面直接调用原路由。

## 决定

- 原签核路由默认拒绝（503），部署方必须显式注入 authorizer。
- authorizer 对请求及任务返回经认证的 actor；拒绝返回空值，异常拒绝且不反射秘密。
- 既有请求字段不变，但 actor 必须与认证身份一致；Repository 使用服务端派生身份。
- 第一实现是单用户、单任务、过期时间明确的独立签署凭据，进程保存 SHA256 摘要。
  它证明持有该能力凭据，不是企业 SSO 或真人身份认证。
- 浏览器来源必须是部署方固定 loopback origin；CLI 可不带 Origin，但仍需签署凭据。
- 不复用页面访问凭据、实例控制凭据或模型密钥；不改变原证据/幂等/状态事务。
- Scope 仅为 Framework Smoke；不新增自动批准、Stage0、性能结论或发布权限。

## 兼容与验收

这是有意收紧的写端点行为：未配置签署身份的旧客户端现在收到503，不能保持匿名写入兼容。
没有数据库迁移。Repository 直接调用的内部测试不变；HTTP 测试须显式注入测试身份。
需覆盖默认拒绝、错误/跨任务/过期凭据、伪造 actor、错误来源、异常秘密不泄露，
以及原事务的状态/证据冲突原样返回。

当前只实现服务端能力与路由保护，尚未接凭据发放/撤销、只读页确认界面、部署和实库联验。
真实待签任务保持原状，不能用本 ADR 或继续开发指令代替人的确认。
