# ADR-0018：Framework Smoke 独立签署身份

状态：实现中，待审；不是人工验收决定。

## 原因

原签核 API 接收调用方 actor 字符串，Repository 校验状态/证据/幂等，但不校验请求身份。
只读结果页接写入口前，必须先补身份边界，避免绕过页面直接调用原路由。

## 决定

- 原签核路由默认拒绝（503），部署方必须显式注入 authorizer。
- authorizer 对请求及任务返回经认证的 actor；拒绝返回空值，异常拒绝且不反射秘密。
- 既有请求字段不变，但 actor 必须与认证身份一致；Repository 使用服务端派生身份。
- 第一实现是单用户、单任务、过期时间明确的独立签署凭据，进程保存 SHA256 摘要。
  它证明持有该能力凭据，不是企业 SSO 或真人身份认证。
- 浏览器来源必须是部署方固定 loopback origin；CLI 可不带 Origin，但仍需签署凭据。
- 不复用页面访问凭据、实例控制凭据或模型密钥；不改变原证据/幂等/状态事务。
- Scope 仅为 Framework Smoke；不新增自动批准、Stage0、性能结论或发布权限。

## 兼容与验收

这是有意收紧的写端点行为：未配置签署身份的旧客户端现在收到503，不能保持匿名写入兼容。
没有数据库迁移。Repository 直接调用的内部测试不变；HTTP 测试须显式注入测试身份。
需覆盖默认拒绝、错误/跨任务/过期凭据、伪造 actor、错误来源、异常秘密不泄露，
以及原事务的状态/证据冲突原样返回。

## 可选本地部署与人工确认

- `ViewerConfig.signing` 默认 `null`；仅同时提供 signing 配置和独立签核 DSN 环境变量时启用。
- 启动时为此实例随机发放单任务签核凭据，有效期默认1800秒、最长3600秒。私有实例目录
  中 `signing-key.txt` 与 access/control 分开；进程仅保留摘要，不把凭据写入 URL 或日志。
- 读取连接仍强制只读。显式签核连接必须指向同一 loopback 数据库/冻结 schema；不迁移、
  不授予角色权限、不把查看密码转换为签核授权。显式提供相同数据库角色仍不是最小权限角色隔离。
- `revoke-signing` 仅凭实例控制凭据撤销后续签核，保留查看能力；停止服务也撤销并清理文件。
  撤销不撤回已进入事务的请求，停止成功前必须等待在途请求退出。重启必须发新凭据。
- 可选结果页只挂载任务签核 GET/POST，不挂载整个控制面。POST 和原 API 共用身份检查函数，
  继续调用 `PostgresRepository.signoff_framework_task`；GET 只读原持久化决定。
- 浏览器先验证身份，再固定任务、评测、证据、决定、理由和幂等 key；第二次点击才提交。
  超时保留原请求，先查持久化结果，再由人以同一 key 重试；409不能静默更换证据。
- 未知结果期间页面内刷新/退出暂时禁用。浏览器强制刷新/关闭会丢失内存中的请求信息，
  重新进入必须先查询数据库已有决定；原状态机仍禁止重复签署。凭据不写浏览器存储。

当前真实待签任务仍未签署，既有实例没有启用写服务；不能用本 ADR 或继续开发指令代替人的确认。
