# Formal 构建成功用量结算

## 本次改动

- 在构建调用含清理结束后，记录一次构建尝试和单调时钟墙钟耗时。
- 将用量与原构建输出一同保存，复用已有 Round Budget 账本结算后才发布候选状态。
- 从持久化结果派生稳定的 Ledger ID、幂等键、时间和证据 Hash。响应丢失后重放不重复计费。
- 停止后只允许对已发生消耗记账，不越过制品发布验权。
- 缺失用量、未知结果、错误候选绑定或非 CPU 构建消耗均拒绝自动结算，不补零或自动退预算。
