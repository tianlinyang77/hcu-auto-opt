## 为什么还不是 Formal

执行时 HCU 7 没有 KFD 进程且利用率为 0，但以下三个非本任务容器仍映射了
`/dev/kfd` 和 `/dev/dri`：

- `pytorch-hcu-core-dev`；
- `pytorch-das-hcu-numerics-runtime-20260811`；
- `dxl-evalscope-server-0731`。

因此无法证明 HCU 7 的排他访问，也没有控制面签发的正式 Lease 和 fencing token。本次
结果只能用于发现环境能力和实现问题。Formal 必须先取得维护窗口，确认其他容器无法访问
HCU 7，再由控制面创建 `mode=formal` 的 Target-bound `Stage0Run`。
